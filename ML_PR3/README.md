## 1. Цель работы

Цель практической работы — разработать и настроить пайплайн предобработки данных для подготовки датасета к обучению модели машинного обучения, исключив утечку информации из тестовой выборки в обучающую.

В ходе работы необходимо:
- разделить данные на обучающую и тестовую выборки;
- определить числовые и категориальные признаки;
- обработать пропущенные значения;
- выполнить масштабирование числовых признаков при необходимости;
- закодировать категориальные признаки;
- объединить этапы предобработки в единый пайплайн;
- обеспечить корректное обучение и оценку модели без утечки данных.

## 2. Рабочее окружение

Для выполнения практической работы используется виртуальное окружение **venv**, встроенное в Python. Оно позволяет изолировать зависимости проекта и избежать конфликтов между версиями установленных библиотек.

Для реализации пайплайна применяются следующие инструменты:

- **Python** — язык программирования для обработки данных и построения моделей машинного обучения.
- **pandas** — загрузка, обработка и анализ табличных данных.
- **NumPy** — выполнение математических операций и работа с массивами.
- **scikit-learn** — разделение выборок, обработка признаков, построение пайплайнов и обучение моделей.
- **Jupyter Notebook** — интерактивная среда для написания и выполнения кода.
- **Matplotlib** и **Seaborn** — построение графиков и визуальный анализ данных.

## 4. Основные этапы выполнения работы

### 4.1. Загрузка и подготовка данных

На первом этапе загружается исходный датасет и проверяются его структура, названия столбцов, типы данных и наличие пропущенных значений.

### 4.2. Разделение данных

Датасет разделяется на обучающую и тестовую выборки с помощью `train_test_split`.

Обучающая выборка используется для настройки и обучения модели, а тестовая — для итоговой оценки качества её работы на данных, которые не участвовали в обучении.

### 4.3. Предобработка признаков

Для числовых признаков при необходимости выполняется заполнение пропущенных значений и масштабирование.

Для категориальных признаков выполняется заполнение пропусков и кодирование категорий в числовой формат.

### 4.4. Создание пайплайна

Для объединения этапов обработки используются `Pipeline` и `ColumnTransformer` из библиотеки `scikit-learn`.

`ColumnTransformer` позволяет применять разные способы обработки к числовым и категориальным признакам, а `Pipeline` объединяет предобработку и обучение модели в единую последовательность действий.

### 4.5. Предотвращение утечки данных

Утечка данных (data leakage) возникает, когда при подготовке или обучении модели используется информация, которая не должна быть доступна на соответствующем этапе.

Чтобы избежать утечки:
- сначала данные разделяются на обучающую и тестовую выборки;
- параметры обработки, например средние значения для заполнения пропусков и параметры масштабирования, определяются только по обучающей выборке;
- тестовая выборка преобразуется с использованием уже настроенных на обучающих данных преобразований;
- тестовая выборка не используется для подбора параметров предобработки и обучения модели.

Использование единого пайплайна помогает обеспечить правильный порядок обработки данных и снизить риск утечки информации.

Пайплайн должен корректно обрабатывать числовые и категориальные признаки, учитывать пропущенные значения и обеспечивать независимость тестовой выборки от процесса настройки предобработки.
