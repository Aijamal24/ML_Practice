# Практическая работа №9
## Support Vector Machine (SVM) и сравнение моделей классификации

### 1. Цель работы

Изучить алгоритм Support Vector Machine (SVM), научиться использовать различные ядра (Linear и RBF), исследовать влияние параметров `C` и `gamma`, а также сравнить SVM с другими алгоритмами машинного обучения.

### 2. Используемые библиотеки

- `NumPy` — работа с массивами и данными.
- `Pandas` — обработка и анализ данных.
- `Matplotlib` — визуализация результатов.
- `Scikit-learn` — построение и обучение моделей.
- `XGBoost` — градиентный бустинг.
- `Time` — измерение времени обучения моделей.

### 3. Выполнение работы

#### Часть 1. Создание искусственного датасета

С помощью `make_moons()` был создан искусственный набор данных:

- Количество объектов: 300.
- Количество классов: 2.
- Количество объектов в каждом классе: 150.
- Уровень шума: 0.25.

Данные были стандартизированы с помощью `StandardScaler`.

#### Часть 2. Линейная модель SVM

Была обучена модель SVM с линейным ядром (`kernel="linear"`).

Результаты:
- Accuracy: 0.860 (86%).
- Количество опорных векторов: 101.

#### Часть 3. Исследование RBF-ядра

Была исследована модель SVM с RBF-ядром и различными значениями параметра `C`.

| C | Accuracy | Опорные векторы |
|---|---:|---:|
| 0.01 | 0.870 | 300 |
| 1 | 0.910 | 92 |
| 100 | 0.937 | 57 |

При увеличении `C` модель стала лучше классифицировать объекты обучающей выборки. Также уменьшилось количество опорных векторов.

#### Часть 4. Подбор гиперпараметров

Для датасета `o_churn_synthetic.csv` была построена модель SVM с RBF-ядром.

Использовались:
- `train_test_split` — разделение данных на обучающую и тестовую выборки.
- `StratifiedKFold` — стратифицированная кросс-валидация.
- `GridSearchCV` — автоматический подбор гиперпараметров.
- `roc_auc` — метрика оценки качества модели.

Проверялись значения:
- C: 0.1, 1, 10, 100.
- Gamma: 0.001, 0.01, 0.1, 1.

**Лучшие параметры:**
- C = 10.
- Gamma = 0.001.
- Средний ROC-AUC на кросс-валидации: 0.777.
- Время поиска: 28 секунд.

#### Часть 5. Сравнение моделей

Были обучены и сравнены пять моделей:

1. SVM RBF.
2. SVM Linear.
3. Logistic Regression.
4. Random Forest.
5. XGBoost.

Результаты тестирования:

| Модель | F1-score | ROC-AUC |
|---|---:|---:|
| SVM RBF | 0.599 | 0.801 |
| SVM Linear | 0.599 | 0.798 |
| Logistic Regression | 0.611 | 0.806 |
| Random Forest | 0.556 | 0.752 |
| XGBoost | 0.586 | 0.792 |

**Результат:** Logistic Regression показала лучшие результаты:
- F1-score = 0.611.
- ROC-AUC = 0.806.

SVM RBF показала ROC-AUC = 0.801, что также является хорошим результатом.

#### Часть 6. Сравнение скорости обучения

Было проведено сравнение `SVC(kernel="rbf")` и `LinearSVC()` на наборах данных разного размера.

| Количество объектов | RBF SVC | LinearSVC |
|---|---:|---:|
| 2 000 | 0.16 сек | 0.01 сек |
| 4 000 | 0.41 сек | 0.01 сек |
| 8 000 | 2.50 сек | 0.01 сек |
| 16 000 | 3.10 сек | 0.03 сек |

**Результат:** LinearSVC обучается значительно быстрее RBF SVC, особенно при увеличении количества объектов.

### 4. Вывод

В ходе практической работы был изучен алгоритм Support Vector Machine (SVM), рассмотрены линейное и RBF-ядра, а также влияние гиперпараметров `C` и `gamma` на качество классификации.

С помощью GridSearchCV были подобраны оптимальные параметры модели SVM. Также было проведено сравнение SVM с Logistic Regression, Random Forest и XGBoost.

По результатам эксперимента Logistic Regression показала лучший F1-score (0.611) и ROC-AUC (0.806). В эксперименте со скоростью обучения LinearSVC оказался значительно быстрее RBF SVC.

Таким образом, выбор алгоритма зависит от размера данных, скорости обучения и требуемого качества классификации.
