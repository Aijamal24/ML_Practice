## 1. Цель работы

Цель практической работы — построить и оценить модель линейной регрессии для прогнозирования стоимости жилья, исследовать взаимосвязи между признаками, проверить наличие мультиколлинеарности и определить, как исключение отдельных признаков влияет на качество модели.

В ходе работы необходимо:
- разделить данные на обучающую и тестовую выборки;
- организовать предобработку данных с помощью `ColumnTransformer`;
- построить базовую модель линейной регрессии;
- исследовать мультиколлинеарность с помощью корреляционной матрицы и VIF;
- построить сокращённую модель без признака `RAD`;
- проанализировать остатки модели;
- сравнить модели по метрикам MAE, RMSE и \(R^2\);
- обосновать выбор итоговой модели.

## 3. Подготовка данных

Перед построением моделей датасет разделяется на обучающую и тестовую выборки. Разделение выполняется до настройки преобразований, чтобы избежать утечки информации.

Для предобработки используется `ColumnTransformer`, позволяющий применять необходимые преобразования к соответствующим группам признаков.

Целевая переменная `MEDV` отделяется от входных признаков. Обучающая выборка используется для построения модели, а тестовая — для оценки качества прогнозирования на данных, не участвовавших в обучении.

## 4. Построение регрессионных моделей

### 4.1. Базовая модель

В качестве базовой модели используется `LinearRegression` из библиотеки `scikit-learn`. Модель обучается на всех выбранных признаках датасета.

Линейная регрессия устанавливает линейную зависимость между входными признаками и целевой переменной, а затем использует её для прогнозирования стоимости жилья.

### 4.2. Анализ мультиколлинеарности

Мультиколлинеарность возникает, когда два или несколько входных признаков сильно связаны между собой. Это может затруднять интерпретацию коэффициентов линейной регрессии и делать их оценки нестабильными.

Для исследования мультиколлинеарности используются:
- тепловая карта корреляционной матрицы (`heatmap`);
- показатель VIF (Variance Inflation Factor).

Полученные результаты позволяют выявить признаки, между которыми существуют сильные линейные взаимосвязи.

### 4.3. Сокращённая модель

Для сравнения строится вторая модель, в которой исключён признак `RAD`.

Цель этого этапа — проверить, как удаление выбранного признака влияет на качество прогнозирования. Обе модели оцениваются на одной и той же тестовой выборке.

Исключение признака не обязательно улучшает результат: решение должно основываться на метриках качества и результатах анализа данных.

## 5. Оценка качества моделей

Для сравнения моделей используются три метрики: MAE, RMSE и \(R^2\).

- **MAE (Mean Absolute Error)** — средняя абсолютная ошибка прогнозирования. Чем меньше значение, тем лучше.
- **RMSE (Root Mean Squared Error)** — корень из средней квадратичной ошибки. Сильнее учитывает большие ошибки. Чем меньше значение, тем лучше.
- **\(R^2\) (коэффициент детерминации)** — показатель того, насколько хорошо модель объясняет изменчивость целевой переменной. Значение, близкое к 1, обычно свидетельствует о более высоком качестве модели.

### Полученные результаты

| Модель | MAE | RMSE | R² |
|---|---:|---:|---:|
| Базовая модель | 3.50 | 4.69 | 0.70 |
| Сокращённая модель без `RAD` | 3.52 | 4.71 | 0.69 |

Результаты показывают, что базовая модель немного превосходит сокращённую по всем трём метрикам. После исключения признака `RAD` значения MAE и RMSE незначительно увеличились, а коэффициент детерминации снизился с 0.70 до 0.69.

Следовательно, удаление этого признака не привело к улучшению качества прогнозирования в проведённом эксперименте.

## 6. Анализ остатков

Остаток — это разница между фактическим значением целевой переменной и предсказанием модели.

Для проверки модели построены график остатков и их гистограмма.

При анализе графиков оцениваются:
- наличие систематических закономерностей в остатках;
- разброс ошибок относительно нулевого уровня;
- возможная неоднородность дисперсии ошибок;
- форма распределения остатков и наличие необычных значений.

В идеальном случае остатки не должны демонстрировать выраженную систематическую структуру. При этом одна только гистограмма не позволяет окончательно подтвердить нормальность ошибок, а отсутствие заметных закономерностей на графике не гарантирует выполнения всех предположений линейной регрессии.

## 7. Выбор итоговой модели

На основании полученных метрик в качестве предпочтительной выбирается базовая модель линейной регрессии, использующая все исходные признаки.

Её преимущества в рамках проведённого эксперимента:
- немного меньшая средняя абсолютная ошибка;
- немного меньшая среднеквадратичная ошибка;
- немного более высокий коэффициент детерминации.

Сокращённая модель может быть полезна, если уменьшение числа признаков необходимо по другим причинам. Однако по представленным результатам удаление `RAD` не улучшает качество прогнозирования.
