# Практическая работа №8
## Градиентный бустинг и ансамблевые методы классификации

### 1. Цель работы

Изучить ансамблевые методы машинного обучения, познакомиться с алгоритмами Random Forest и XGBoost, исследовать влияние гиперпараметров на качество модели и сравнить результаты с Logistic Regression.

### 2. Используемые библиотеки

- `Pandas` — загрузка и обработка данных.
- `Scikit-learn` — подготовка данных, создание и оценка моделей.
- `XGBoost` — реализация градиентного бустинга.
- `NumPy` — работа с числовыми данными.
- `Time` — измерение времени обучения моделей.

### 3. Подготовка данных

Для работы использовался датасет `o_churn_synthetic.csv`.

Целевая переменная — `churn`, которая показывает, ушёл ли клиент.

Выполнены следующие действия:

- Удалены столбцы `churn` и `subscriber_code` из признаков.
- Данные разделены на обучающую и тестовую выборки.
- Использован `train_test_split` с параметрами `test_size=0.2`, `stratify=y`, `random_state=42`.
- Категориальные признаки `region` и `tariff` преобразованы с помощью `OneHotEncoder`.

Размеры выборок:

| Выборка | Количество строк |
|---|---:|
| Train | 2400 |
| Test | 600 |

После One-Hot Encoding количество признаков увеличилось до 22.

### 4. Обучение XGBoost и Random Forest

Были обучены две модели:

**XGBoost**
- Количество деревьев: 300.
- Learning rate: 0.05.
- Максимальная глубина: 4.

Результаты:
- F1 train: 0.789.
- F1 test: 0.574.
- ROC-AUC: 0.779.
- Время обучения: 2.04 секунды.

**Random Forest**
- Количество деревьев: 100.
- Random state: 42.

Результаты:
- F1 train: 1.000.
- F1 test: 0.556.
- ROC-AUC: 0.752.
- Время обучения: 1.64 секунды.

Random Forest показал идеальный результат на обучающей выборке, но более низкий результат на тестовой. Это указывает на переобучение модели.

### 5. Early Stopping

Для XGBoost был применён метод Early Stopping.

Данные были дополнительно разделены:
- Train: 1920 строк.
- Validation: 480 строк.
- Test: 600 строк.

Количество признаков после One-Hot Encoding: 22.

Использовались параметры:
- `n_estimators=2000`.
- `learning_rate=0.05`.
- `max_depth=4`.
- `early_stopping_rounds=50`.

Результаты:
- Лучшая итерация: 78.
- Logloss на validation: 0.5405.

Early Stopping позволяет остановить обучение, когда качество модели на проверочной выборке перестаёт улучшаться.

### 7. Сравнение моделей

В заключительной части были сравнены три алгоритма:
1. Logistic Regression.
2. Random Forest.
3. XGBoost.

Результаты:

| Модель | F1 train | F1 test | ROC-AUC |
|---|---:|---:|---:|
| Logistic Regression | 0.594 | 0.611 | 0.806 |
| Random Forest | 1.000 | 0.556 | 0.752 |
| XGBoost | 0.645 | 0.586 | 0.792 |

Время обучения:
- Logistic Regression: 0.04 секунды.
- Random Forest: 0.86 секунды.
- XGBoost: 0.52 секунды.

**Лучшей моделью стала Logistic Regression:**
- F1 test = 0.611.
- ROC-AUC = 0.806.

Она показала лучшие результаты на тестовой выборке и самое быстрое время обучения.

### 8. Вывод

В ходе практической работы были изучены ансамблевые методы машинного обучения, включая Random Forest и XGBoost.

Было проведено обучение моделей, исследовано влияние гиперпараметров `learning_rate` и `max_depth`, а также применён Early Stopping для предотвращения лишних итераций обучения.

В результате сравнения Logistic Regression показала лучшие значения F1-score (0.611) и ROC-AUC (0.806). Random Forest продемонстрировал признаки переобучения, а XGBoost показал ROC-AUC 0.792.

Таким образом, более сложные ансамблевые алгоритмы не всегда превосходят простые модели. Выбор алгоритма должен основываться на результатах тестирования и качестве предсказаний.
