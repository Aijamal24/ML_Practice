## 1. Цель работы

Цель практической работы — выполнить разведочный анализ данных (Exploratory Data Analysis, EDA), изучить структуру и основные характеристики табличного датасета, выявить возможные проблемы качества данных и разработать план их устранения перед использованием данных в моделях машинного обучения.

В ходе работы необходимо:
- изучить размер и структуру датасета;
- определить типы признаков и проверить корректность их значений;
- обнаружить пропущенные значения и дубликаты;
- исследовать распределения числовых и категориальных признаков;
- выявить возможные выбросы;
- изучить взаимосвязи между признаками с помощью статистических показателей и графиков;
- сформулировать выводы и предложить способы предварительной обработки данных.

## 2. Рабочее окружение

Для выполнения практической работы используется виртуальное окружение **venv**, встроенное в Python.

Виртуальное окружение позволяет изолировать библиотеки и зависимости проекта от других проектов на компьютере. Это помогает избежать конфликтов между версиями пакетов и поддерживать стабильную работу программного кода.

Для проведения EDA используются следующие инструменты:

- **Python** — язык программирования для анализа и обработки данных.
- **pandas** — загрузка, обработка и исследование табличных данных.
- **NumPy** — выполнение математических операций.
- **Matplotlib** — построение графиков и диаграмм.
- **Seaborn** — визуализация распределений, корреляций и взаимосвязей между признаками.
- **Jupyter Notebook** — интерактивная среда для выполнения кода и представления результатов анализа.
- **scikit-learn** — инструменты предварительной обработки данных и подготовки к построению моделей машинного обучения.

## 3. Создание виртуального окружения

Для изоляции зависимостей проекта создаётся виртуальное окружение `.venv`.

### Шаг 1. Создание окружения

В терминале, открытом в папке проекта, выполняется команда:

```bash
python -m venv .venv
```

Команда создаёт папку `.venv`, в которой размещаются необходимые файлы виртуального окружения.

### Шаг 2. Активация окружения

В операционной системе Windows выполняется команда:

```bash
.venv\Scripts\activate
```

После успешной активации в начале строки терминала должно появиться обозначение `(.venv)`.

### Шаг 3. Установка библиотек

После активации виртуального окружения устанавливаются необходимые библиотеки:

```bash
python -m pip install pandas numpy matplotlib seaborn jupyter scikit-learn
```

### Шаг 4. Проверка установки

Для проверки установленных пакетов выполняется команда:

```bash
python -m pip list
```

В результате отображается список установленных библиотек и их версий.

## 4. Основные этапы разведочного анализа данных

Разведочный анализ данных выполняется последовательно, чтобы получить представление о качестве, структуре и особенностях исследуемого датасета.

1. **Загрузка данных.** Импорт датасета и проверка успешности чтения файла.
2. **Изучение структуры.** Определение количества строк и столбцов, названий признаков и типов данных.
3. **Проверка качества данных.** Поиск пропущенных значений, дубликатов и некорректных значений.
4. **Статистический анализ.** Расчёт основных статистических характеристик числовых признаков.
5. **Анализ распределений.** Построение гистограмм и диаграмм для изучения распределения признаков.
6. **Поиск выбросов.** Исследование экстремальных значений с помощью описательной статистики и диаграмм размаха (boxplot).
7. **Анализ взаимосвязей.** Изучение корреляций между числовыми признаками и построение диаграмм рассеяния.
8. **Формулирование выводов.** Определение обнаруженных проблем и разработка плана предварительной обработки данных.

## 5. Ожидаемый результат

В результате выполнения практической работы должен быть получен отчёт, содержащий описание датасета, результаты проверки качества данных, статистические характеристики, графики распределений и взаимосвязей признаков, а также выводы о выявленных проблемах и способах их устранения.

## 6. Вывод

Разведочный анализ данных является важным этапом машинного обучения, поскольку позволяет оценить качество исходного датасета, обнаружить потенциальные ошибки и определить особенности распределения признаков. Результаты EDA помогают обоснованно выбрать методы предварительной обработки данных и подготовить датасет к дальнейшему обучению и оценке моделей машинного обучения.
