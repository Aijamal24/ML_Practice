# Практическая работа № 7. Random Forest

## 1. Цель работы

Изучить алгоритм Random Forest для решения задачи регрессии, выполнить подбор гиперпараметров, оценить качество моделей, определить важность признаков и исследовать возможность уменьшения их количества.

## 2. Используемый датасет

**Название:** California Housing

**Источник:** [Kaggle — California Housing](https://www.kaggle.com/datasets/sooyoungher/california-housing)

Датасет содержит информацию о жилых районах Калифорнии. На основе характеристик районов модель предсказывает медианную стоимость жилья.

Основные характеристики датасета:
- Количество строк: около 20 640.
- Количество признаков: 8 исходных входных признаков.
- Целевая переменная: `median_house_value`.

## 3. Используемые библиотеки

- `pandas` — обработка и анализ данных.
- `numpy` — математические вычисления.
- `matplotlib` — построение графиков.
- `scikit-learn` — обучение моделей и оценка качества.

## 4. Этапы выполнения работы

### Шаг 1. Подготовка данных

Данные загружаются и проверяются на наличие пропущенных значений. Выполняется необходимая предварительная обработка признаков.

### Шаг 2. Разделение данных

Датасет разделяется на обучающую и тестовую выборки. Обучающая выборка используется для обучения моделей, тестовая — для оценки качества предсказаний.

### Шаг 3. Обучение Decision Tree

Обучается модель дерева решений `DecisionTreeRegressor`. Полученные предсказания используются для оценки качества модели.

### Шаг 4. Обучение Random Forest

Обучается модель `RandomForestRegressor` со стандартными параметрами. Результаты сравниваются с Decision Tree.

### Шаг 5. Подбор гиперпараметров

Для поиска лучших параметров используется `GridSearchCV`.

Настраиваемые параметры:
- `n_estimators` — количество деревьев.
- `max_depth` — максимальная глубина деревьев.
- `min_samples_leaf` — минимальное количество объектов в листе.

Для оценки используется пятикратная или трёхкратная кросс-валидация в зависимости от выбранной конфигурации.

### Шаг 6. Оценка лучшей модели

Для лучшей модели Random Forest рассчитываются метрики MAE, RMSE и R².

### Шаг 7. Сравнение моделей

Сравниваются три модели:
1. Decision Tree.
2. Random Forest со стандартными параметрами.
3. Random Forest с подобранными гиперпараметрами.

Результаты представляются в виде таблицы.

### Шаг 8. Анализ важности признаков

С помощью `feature_importances_` определяется относительная важность входных признаков. Результаты выводятся в таблицу и отображаются на горизонтальном столбчатом графике.

### Шаг 9. Отбор признаков

Признаки сортируются по важности. Последовательно обучаются модели с разным количеством наиболее важных признаков, после чего рассчитывается RMSE.

### Шаг 10. Анализ количества признаков

Строится график зависимости RMSE от количества используемых признаков. На основании результатов определяется, можно ли уменьшить количество признаков без существенного ухудшения качества.

В качестве критерия используется допустимое увеличение RMSE не более чем на 1% относительно полной модели.

## 5. Метрики оценки качества

| Метрика | Описание | Лучшее значение |
|---|---|---|
| MAE | Средняя абсолютная ошибка предсказаний | Чем меньше, тем лучше |
| RMSE | Квадратный корень из средней квадратичной ошибки | Чем меньше, тем лучше |
| R² | Коэффициент детерминации | Чем ближе к 1, тем лучше |
