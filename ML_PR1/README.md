## 1. Цель работы

Цель практической работы — подготовить рабочее окружение для выполнения задач по машинному обучению, изучить базовую структуру ML-проекта и освоить основные методы первичного анализа табличных данных.

В ходе работы необходимо создать виртуальное окружение Python, установить необходимые библиотеки, подготовить рабочую директорию проекта и выполнить первоначальное изучение набора данных.

## 2. Настройка рабочего окружения

Для выполнения практических работ выбрано виртуальное окружение **venv**, встроенное в Python.

Виртуальное окружение позволяет изолировать зависимости отдельного проекта от других проектов на компьютере. Это помогает избежать конфликтов между версиями библиотек и обеспечивает стабильную работу программного кода.

Основные преимущества `venv`:
- входит в стандартную поставку Python и не требует отдельной установки;
- позволяет устанавливать библиотеки отдельно для каждого проекта;
- упрощает управление зависимостями;
- подходит для выполнения учебных заданий по машинному обучению.

## 3. Используемые инструменты и библиотеки

Для выполнения практической работы используется следующий программный инструментарий:

- **Python 3.11 или новее** — язык программирования, используемый для обработки и анализа данных.
- **pandas** — библиотека для загрузки, обработки и анализа табличных данных.
- **NumPy** — библиотека для выполнения математических операций и работы с массивами.
- **Matplotlib** — библиотека для построения графиков и визуализации данных.
- **Jupyter** — интерактивная среда для написания и выполнения кода по отдельным ячейкам.
- **scikit-learn** — библиотека, предоставляющая инструменты для предварительной обработки данных и построения моделей машинного обучения.

## 4. Создание виртуального окружения и установка библиотек

Для настройки рабочего окружения необходимо выполнить следующие команды в терминале.

**Шаг 1. Создание виртуального окружения**

```bash
python -m venv venv
```

Команда создаёт виртуальное окружение с именем `venv` в текущей директории проекта.

**Шаг 2. Активация виртуального окружения**

Для Windows используется следующая команда:

```bash
venv\Scripts\activate
```

После успешной активации в начале строки терминала должно появиться обозначение `(venv)`.

**Шаг 3. Установка необходимых библиотек**

```bash
python -m pip install pandas numpy matplotlib jupyter scikit-learn
```

Эта команда устанавливает все библиотеки, необходимые для выполнения практической работы.

**Шаг 4. Проверка установки**

Для проверки корректности установки библиотек можно выполнить команду:

```bash
python -m pip list
```

В результате отобразится список установленных пакетов и их версий.
