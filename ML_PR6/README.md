## 4. Основные этапы классификации текстов

### 4.1. Подготовка данных

На первом этапе загружается датасет, содержащий текстовые данные и соответствующие метки классов. Проверяются структура данных, наличие пропущенных значений и распределение текстов по классам.

### 4.2. Предобработка текста

Для повышения согласованности текстовых данных выполняются следующие операции:

- перевод текста в нижний регистр;
- удаление знаков препинания и цифр, если они не несут полезной информации для задачи;
- разделение текста на отдельные слова (токены);
- удаление стоп-слов, которые не помогают различать классы;
- подготовка очищенного текста для последующей векторизации.

Предобработка позволяет привести тексты к единому формату и уменьшить количество неинформативных элементов.

### 4.3. Векторизация текста

Алгоритмы машинного обучения работают с числовыми признаками, поэтому текст необходимо преобразовать в числовое представление.

В работе рассматриваются два метода:

**Bag of Words (CountVectorizer)** — представляет текст в виде вектора частот слов. Каждый признак соответствует слову из словаря, а значение показывает, сколько раз это слово встречается в документе.

**TF-IDF (TfidfVectorizer)** — учитывает частоту слова в конкретном документе и его распространённость во всём наборе документов. Слова, встречающиеся во многих документах, обычно получают меньший вес, чем более характерные для отдельных текстов.

Дополнительно можно сравнить использование униграмм и биграмм. Униграммы представляют отдельные слова, а биграммы — последовательности из двух соседних слов.

### 4.4. Построение классификатора

Для классификации используется алгоритм **Multinomial Naive Bayes** (`MultinomialNB`), который часто применяется для задач классификации текстов.

Модель обучается на векторизованных текстах и соответствующих метках классов, после чего прогнозирует классы для новых документов.

Для корректной оценки качества данные предварительно разделяются на обучающую и тестовую выборки. Векторизатор настраивается только на обучающих текстах, чтобы избежать утечки информации из тестовой выборки.

### 4.5. Оценка качества модели

Качество классификации оценивается с помощью следующих инструментов:

- **Accuracy** — доля правильных предсказаний среди всех предсказаний;
- **Precision** — доля правильных положительных предсказаний среди всех предсказаний данного класса;
- **Recall** — доля объектов данного класса, которые модель смогла правильно обнаружить;
- **F1-score** — гармоническое среднее Precision и Recall;
- **Confusion Matrix** — матрица ошибок, показывающая количество правильных и ошибочных классификаций по каждому классу.

При необходимости дополнительно сравниваются результаты моделей, использующих CountVectorizer и TF-IDF, а также униграммы и биграммы.
